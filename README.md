# Map of Experience · Android downloads

Android test builds for [Map of Experience](https://mapofxp.com).
This repository contains download information and APK release assets only.
The application source is maintained separately in a private repository.

## Install on your phone

1. Open [Releases](https://github.com/MubashirullahD/map-of-experience-android/releases) on your Android phone.
2. Download the APK attached to the test release and open it.
3. If Android asks, allow your browser or Files app to install this download.

Use the newest test prerelease in [Releases](https://github.com/MubashirullahD/map-of-experience-android/releases)
for the current version and its changes. As of 5 November 2026, that is
[2.8.3 (version code 15)](https://github.com/MubashirullahD/map-of-experience-android/releases/tag/gallery-map-v2.8.3-test.11).

The current app uses Expo / React Native. It opens the live Map of Experience site
and adds a native gallery map, photo/video selection and posting, video trimming,
and Android sharing. Photo-location access is optional. The Expo app replaced the
Capacitor 1.x app using the same app id (`com.mapofxp.app`) and signing certificate,
so it can install over that app as an update.

The 2.8.3 APK needs Android 7.0 or later on a 64-bit ARM phone. Check each release's
notes for its requirements and validation; the public website and the native app
have separate features and release schedules.

These are debug-signed test builds, distributed as prereleases rather than Play
Store releases. Install updates over the existing app when Android offers it.
