# Map of Experience · Android downloads

Android test builds for [Map of Experience](https://mapofxp.com).
This repository contains download information and APK release assets only.
The application source is maintained separately in a private repository.

## Install on your phone

1. Open [Releases](https://github.com/MubashirullahD/map-of-experience-android/releases) on your Android phone.
2. Download the APK attached to the test release and open it.
3. If Android asks, allow your browser or Files app to install this download.

The current test build is version 1.1. It opens the live Map of Experience site
and adds native photo handling that preserves available original photo locations.
Photo-location access is optional. The gallery-map feature is developed separately
and is not part of the current hosted interface.

These are debug-signed test builds, distributed as prereleases rather than Play
Store releases. Install updates over the existing app when Android offers it.
